# Keep View Explorer

## Changes since 1.43.1

- Explain missing and invalid creation dates in an optional dialog, with a preview-first timestamp import shortcut and a persistent Don't show again option.
- Show cards automatically when a new view opens, without having to change the sort order.
- Validate saved settings and search-cache entries before use.
- Support Obsidian's settings search on 1.13 and later; retain the settings screen on older versions.
- Reduce broad CSS selectors and overrides while keeping the desktop and mobile layouts.
- Prepare release assets with GitHub provenance attestations.

Browse Markdown notes as cards or in a folder tree. Combine tags, folders, dates and full-text search, then organize selected notes in bulk.

- English and Japanese interface.
- Desktop and mobile layouts.
- Relative paths by default when exporting results.
- Optional compressed local search cache.
- Creation timestamp import for Markdown notes migrated from Google Keep.

Requires Obsidian 1.8.7 or later. Install from the [community directory](https://community.obsidian.md/plugins/keep-view).

For manual installation, copy the attached `main.js`, `manifest.json` and `styles.css` into the vault's plugin folder for `keep-view`, then enable it in Obsidian. The repository README contains usage and data-handling details.
