# Security

Please do not post private vault contents, paths, credentials or exploit details in public issues. When the repository is published, use GitHub's private vulnerability reporting feature under **Security → Report a vulnerability**. The maintainer must enable that feature first.

If that button is unavailable, open an issue requesting a private reporting channel without including vulnerability details. Only the latest released version is intended to receive fixes.

Keep View Explorer does not add telemetry or send search queries to a service. Markdown rendering can load external resources referenced in notes. The local search cache contains compressed, unencrypted note text. See the README for data handling details.
